Add the repository once.

Adding the repository lets your software centre find {{.RepoTitle}} and bring its updates with your other apps. This needs Flatpak 1.17 or later.

flatpak remote-add --user --if-not-exists {{.RemoteName}} {{.PagesURL}}/{{.RemoteName}}.flatpakrepo
Download the repository file
With Flatpak older than 1.17

Older versions cannot read where the signatures live from the repository file. Add the repository, then tell Flatpak where to find them:

flatpak remote-add --if-not-exists --user --no-gpg-verify {{.RemoteName}} oci+{{.PagesURL}}{{if .Signing.Enabled}}
flatpak remote-modify --user --signature-lookaside={{.PagesURL}}/{{.Signing.Lookaside}} {{.RemoteName}}{{end}}
