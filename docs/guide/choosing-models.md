# Choosing models

Nocturne picks a set of models for your computer when it is set up, and you never need to change them.
If you want to, the advanced view lets you pick a model for each job: answering, reading recordings,
reading aloud and finding memories. This page uses the word model because the advanced view does.

## What you can pick

Each job lists only what suits it from the private engine's own catalogue. You cannot add a model
from somewhere else. Every row shows whether it fits this computer:

- Fits: comfortable.
- Tight: it works but leaves little room for other apps.
- Won't fit, or Can't use: greyed, with one reason, such as not enough memory or not enough free space.

A model Nocturne has not tried says "Not tested with Nocturne". Reading aloud has one choice today.

## Downloads

A model that is not on this computer is downloaded only after you say yes, and Nocturne tells you the
size first. You can pause, cancel or try again. Cancelling removes the partial download. Each finished download
is listed in Privacy. Nocturne keeps using the current model until the new one is ready, and then
changes in one step.

## The old model

After a change Nocturne offers to keep the old model, which is the default, or to remove it and free its
space. Nothing is removed unless you choose to.

## Changing how memories are found

A new finding model means Nocturne reads your memories again with it. It does this quietly in the
background and shows progress, answers keep using the old way meanwhile, and it swaps over all at once
when it is done. If you quit, it carries on afterwards. If you cancel, nothing changes.

## Back to the preset

"Reset to" your computer's tier clears all your choices.
