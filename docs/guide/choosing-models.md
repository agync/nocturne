# Choosing models

Nocturne picks a set of models for your computer when it is set up, and you never need to change them.
If you want to, Settings has "Choose what runs each job" (also linked from the advanced details as
"Choose for each job…"), which lets you pick a model for each job: answering, reading recordings,
reading aloud and finding memories. This page uses the word model because the advanced view does.

## What you can pick

Each job lists only what suits it from the private engine's own catalogue. You cannot add a model
from somewhere else. For answering, that means models that also read photos and do not think aloud.
Every row shows whether it fits this computer:

- Fits: comfortable.
- Tight: it works but leaves little room for other apps.
- Won't fit, or Can't use: greyed, with one reason ("Too much memory beside the other jobs.", "Needs
  … more free space." or "Not available on this computer."), and a "Why?" link.

A model Nocturne has not tried says "Not tested with Nocturne". Reading aloud has one choice today.
Only one change can run at a time, and none while setup is downloading.

## Downloads

A model that is not on this computer is downloaded only after you say yes, and Nocturne tells you the
size first. You can pause, cancel or try again. Cancelling removes the partial download. Each
finished download is listed in Privacy. While a download runs, Online answers is set aside and
questions are answered on this computer. Nocturne keeps using the current model until the new one
is ready, and then changes in one step. A model already on this computer is used at once.

## The old model

After a change Nocturne offers "Keep it", so you can switch back without downloading, or "Remove, free" with its size. Nothing is removed unless you choose to.

## Changing how memories are found

A new finding model means Nocturne reads your memories again with it. It does this quietly in the
background and shows progress, answers keep using the old way meanwhile, and it swaps over all at once
when it is done. If you quit, it carries on afterwards. If you cancel ("Cancel, keep the old way"),
nothing changes. If it cannot finish, it stops the same way and the old way stays.

## Back to the preset

"Reset to" your computer's tier puts each job back on the model that tier uses, when each is on
this computer. If you had changed the finding model, putting it back also means a re-read.
