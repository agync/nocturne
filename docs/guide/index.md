## What Nocturne does

You keep things as you go: a photo of a letter, a voice note, a file, a line of text. Nocturne
reads them overnight while your computer is plugged in and idle, joins them up, and hands you one
page each morning. Ask it a question and it answers only from what you kept, and shows you the
originals it used. Everything stays on this computer.

## What this version does not do

Nocturne is deliberately small. These are choices, not missing pieces you need to work around.

- It does not print by itself. You can print the morning page whenever you choose to.
- It does not remind you. It lists what needs you on the page and in the app, and sends one quiet
  note when the page is ready if you allow that. It never nags.
- It speaks English (UK) only, for the app and for the spoken page.
- It has no "Keep anyway". If you have already kept the same thing, Nocturne tells you when and
  keeps nothing new.
- It does not open password-locked PDFs. Save an unlocked copy and drop that in instead.
- It has no Windows installer yet, and no macOS version. Linux comes as an AppImage, an rpm and a
  deb.
