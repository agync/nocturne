[Control chips and easier reading in setup](/design/control-chips.md) is built. A sentence that
sends the person to a place or control now shows it as a chip with the control's own words, and a
gear when the control has one. The rail's Settings link has the gear. The Tiny box on step 1 is
two short lines with chips, "Why this one?" opens a size table, and every button that opens text
in place has the same right-then-down chevron. Setup copy, sizes and spacing follow the measurable
reading rules, and a test holds them.
