[Privacy policy](/design/privacy-policy.md) question 7 no longer asks for health data to be
declared as shared in Apple's privacy details. The owner set the App Store label to Data Not
Collected: Apple counts only data that reaches the developer or the developer's partners, and a
provider the person chooses with their own key is neither. Play's Data safety form keeps the
declaration until it is filled in.
