a third part. The phone reads only while it charges, yet This phone said "Reading · 0 of 89", which
looked stuck. On battery it now says "Waiting to charge · 89 to read", with why ("so it doesn't run
the battery down") and "Read now", which reads while Nocturne stays open and uses some battery. Read
now is only ever the person's act. It stops when they leave Nocturne, when everything is read, at 20
per cent battery or with the phone's battery saving on, on a pause by the limit and on each trouble,
and says why. The part holds the state table, every string, accessibility, the code change it
implies in the mind's charging gate, two open questions, mockups and before and after renders.
