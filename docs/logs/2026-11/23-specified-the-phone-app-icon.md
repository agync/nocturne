[Nocturne on Android and iPhone](/design/phone-apps.md#app-icon) gains an App icon section: the
desktop's half-lit moon on the night background, as an Android adaptive icon with a monochrome
version for themed icons, a 1024 square for iPhone and a 512 square for the Play listing. The
sources and a preview sheet are in `docs/design/mockups/phone-icon/`, with steps for the build to
replace the default launcher icon.
