[Backup on a phone of its own](/design/phone-backup.md) gains the words the first build of its
screens found missing. In This phone: an Android account chosen whose Drive already holds another
backup, which stops the backup until the person chooses; the phrase set again before the backup
can carry on in a new account; and every hint for a backup that has no finished night yet. An
iPhone opens only Nocturne's own page in Settings, so the lines that send the person there say
where to go next. A restore that waits for Wi-Fi says so, and the counts before bringing a backup's
things in read without a first day when the backup does not hold one. Restoring this phone's own
backup does not ask whether to make the backups from this phone.
