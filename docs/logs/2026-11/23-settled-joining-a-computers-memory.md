[Moving your memory](/design/moving-memory.md#when-the-computer-already-holds-a-memory) records the
owner's answers as [decision 33](/design/phone-parity.md#decisions): "Bring the phone's things in"
is selected when the computer asks, a memory put aside after "Use this computer's memory" can still
be brought in later, and the two choices apply to any move into a computer that already holds a
memory.
