Connect to the service you chose.

Copy three things from its website. They’re usually on a page about keys, or in its quick start guide.

Address API URL https://api.example.com/v1 Starts with https://, or http:// for a server on this computer or your own network. Copy all of it.
Key API key •••••••••••••••••••••••• A long code the service gives you. It stays on this computer, locked away.
Which one to use model name reader-small Type it, or choose from the list On api.example.com’s list.

Which service?

Any service that answers the way OpenAI’s does. For example OpenAI, OpenRouter, Mistral, Groq or DeepInfra.

Nocturne doesn’t recommend one. Each has its own prices, and its own page about what it keeps. Read that before you choose.

Nocturne gives the key only to its own engine on this computer, which uses it to reach that address and nowhere else.
